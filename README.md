 # UK Radio Frequencies

A loose collection of UK radio frequencies, created as CSV files for use with CHIRP or similar apps. I found that a lot of this information is widely known in the amateur radio space, but then the access to the information is either obfuscated by being shared in proprietary formats in facebook groups, paywalled, or in random youtube videos.

## Using the data
Open a CSV file in a spreadsheet application and then load it into your tool of choice. In my case, I used CHIRP to first download a copy of the preset file in my radio to my computer, and then copy/pasted from the appropriate CSV into CHIRP.

## Contributions
Corrections and additions are welcome. Please keep entries consistent with the relevant column format and include a source where possible.

## Disclaimer
### Technical

The frequency information may be incomplete or out of date, so if you are looking to be using any of this for "proper" reasons, verify the details with an authoritative source. I'm just some guy on github, and you'd be kicking yourself if you copied something from here and then had to rely on a frequency I listed with a typo for something important.

When I was working with CHIRP, I found that the power settings were either 8W or 50W, and this may not be appropriate for the frequency (PMR446 for example is limited to 0.5W) or individual radios. Therefore uploads may either have this value set blank, or set to whatever CHIRP assigned for me at first. Please consider this when using the files from here and set according to your usage and the relevant regulations.

### General
Look, not to be a debbie-downer, but there are regulations and laws that govern the use of radios, so follow applicable UK laws and regulations in relation to transmitting in the UK. In fact, just don't transmit at all if you are not licensed to do so.
